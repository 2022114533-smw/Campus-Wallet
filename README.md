# Campus-Wallet
대학생 가계부 프로젝트
## 프로젝트 이름
**"대학생 가계부 (Campus Wallet)"**

---

## 한 문장 설명
> 대학생이 매일 간편하게 수입과 지출을 기록하고, 한 달 소비 패턴을 한눈에 파악할 수 있는 가계부 프로그램

---

## 풀려는 문제 또는 만들려는 이유
용돈과 아르바이트 월급을 받아도 어느 순간 돈이 사라져 있는 경험을 반복하고 있다. 돈이 어디에 얼마나 쓰였는지 파악이 안 되다 보니 소비를 줄이고 싶어도 어디서 줄여야 할지 모른다. 기존 가계부 앱은 기능이 너무 많거나 복잡해서 매일 기록하는 것이 오히려 귀찮게 느껴진다. 따라서 **복잡한 설정 없이 빠르게 입력하고 바로 확인**할 수 있는 간단한 가계부가 필요하다. 매일 기록하는 습관을 통해 한 달 소비 패턴을 분석하고 불필요한 지출을 스스로 인식하는 것이 목표이다.

---

## 핵심 기능 3가지

| 구분 | 기능 | 설명 |
|------|------|------|
| ✅ 필수 | **수입/지출 기록** | 날짜, 카테고리(식비·교통·여가 등), 금액, 메모를 입력하여 저장 |
| ➕ 추가 1 | **월별 소비 요약** | 한 달 총 수입, 총 지출, 잔액을 계산하고 카테고리별 지출 비중 출력 |
| ➕ 추가 2 | **지출 TOP 카테고리 분석** | 이번 달 가장 많이 쓴 카테고리 순위를 보여줘 소비 습관 파악 가능 |

---

## 예상 사용자
- **나 자신** (용돈·아르바이트 수입을 관리하는 대학생)
- 복잡한 앱 없이 간단하게 가계부를 쓰고 싶은 대학생 누구나

---

## 결과물 형태
> **CLI (Command Line Interface)**
> 터미널에서 메뉴를 선택하는 방식으로 구현 → 빠른 입력, 군더더기 없는 구조

---

## 사용할 Python 개념

| 개념 | 활용 내용 |
|------|-----------|
| **변수 / 자료형** | 금액, 날짜, 카테고리 등 데이터 저장 |
| **리스트 / 딕셔너리** | 거래 내역 목록 및 카테고리별 합계 저장 |
| **함수** | 기록 추가, 요약 출력, 분석 등 기능별 분리 |
| **조건문 / 반복문** | 메뉴 선택 처리, 데이터 순회 및 필터링 |
| **파일 입출력 (CSV)** | 기록을 파일로 저장하여 프로그램 종료 후에도 데이터 유지 |
