💳 Campus Wallet

간단한 CLI(Command Line Interface) 기반 가계부 프로그램입니다.

Python과 CSV 파일을 이용하여 거래 내역을 저장하고, 카테고리별 예산을 관리하며 소비 현황을 확인할 수 있습니다.

⸻

📌 프로젝트 소개

Campus Wallet은 대학생들이 쉽게 사용할 수 있는 간단한 가계부 프로그램입니다.

사용자는 거래 내역을 입력하고, 카테고리별 예산을 설정할 수 있으며, 예산 대비 소비 현황과 하루 사용 가능한 금액을 확인할 수 있습니다.

모든 데이터는 CSV 파일에 저장되어 프로그램을 종료해도 유지됩니다.

⸻

✨ 주요 기능

MUST 기능

1. 거래 입력

* 날짜
* 카테고리
* 금액(수입:+ / 지출:-)
* 메모

입력한 내용은 records.csv에 저장됩니다.

⸻

2. 거래 목록 조회

저장된 모든 거래 내역을 출력합니다.

출력 예시

2026-05-01 | 식비 | -8500원 | 점심
2026-05-02 | 용돈 | 100000원 | 부모님

⸻

3. 예산 설정

카테고리별 월 예산을 설정합니다.

예시

식비 : 300000원
교통 : 100000원

예산 정보는 budgets.csv에 저장됩니다.

⸻

4. 예산 대비 현황

카테고리별

* 사용 금액
* 예산
* 사용률(%)

을 확인할 수 있습니다.

또한 현재 전체 잔액도 함께 출력됩니다.

예시

식비 120,000 / 300,000원 (40% 사용)
현재 잔액 : 450,000원

⸻

⭐ NICE 기능

1. 예산 초과 경고

지출을 입력하면 자동으로 예산을 확인합니다.

* 예산의 80% 이상 사용 시 경고
* 예산 초과 시 초과 경고 출력

예시

⚠ '식비' 예산의 85%를 썼어요.
⚠ '식비' 예산을 초과했어요!

⸻

2. 하루 사용 가능 금액 계산

이번 달

* 남은 예산
* 남은 날짜

를 계산하여 하루에 사용할 수 있는 금액을 알려줍니다.

예시

남은 예산 : 180,000원
남은 날 : 15일
하루에 약 12,000원 사용 가능

⸻

3. 소비 분석

카테고리별 지출을 분석하여

가장 많이 소비한 카테고리를 출력합니다.

예시

이번 달 가장 많이 쓴 곳 : 식비 (210,000원)

⸻

4. 데이터 초기화

거래 기록과 예산을 모두 삭제하여 프로그램을 처음 상태로 초기화합니다.

초기화 전 사용자에게 확인 메시지를 출력하여 실수로 삭제하는 것을 방지합니다.
