# Campus Wallet — 대학생 예산 도우미 가계부

## 무엇을 하는 프로그램인가요?

카테고리별로 한 달 예산을 정해두면, 수입과 지출을 기록할 때마다 예산을 얼마나 썼는지·하루에 얼마 쓸 수 있는지 알려주는 터미널(CLI) 가계부입니다. 단순히 과거를 기록하는 데 그치지 않고, 예산이라는 기준으로 앞으로의 소비를 관리하도록 돕는 것이 목표입니다.

이 프로그램은 VS Code에서 개발하고 실행했습니다.

1. Python 3.10 이상 설치 (VS Code에는 Python 확장도 함께 설치)
2. VS Code에서 `campus_wallet.py`를 연 뒤, 오른쪽 위 ▶ 실행 버튼을 누르거나 터미널에 아래 명령을 입력
   ```
   python campus_wallet.py
   ```
3. 처음 실행하면 같은 폴더에 `records.csv`(거래 기록), `budgets.csv`(예산)가 자동으로 만들어집니다. 프로그램을 껐다 켜도 데이터가 유지됩니다.

## 핵심 기능

- 수입/지출 기록 (날짜·카테고리·금액·메모). 수입은 `+`, 지출은 `-`로 입력
- 거래를 CSV 파일에 저장하고 다시 켤 때 불러오기
- 카테고리별 한 달 예산 설정
- 예산 대비 현황 보기 (카테고리별 사용률 % + 잔액)
- 예산 초과/임박 시 경고 (지출 입력 직후)
- 이번 달 남은 날로 나눈 "하루에 쓸 수 있는 돈" 계산
- 소비 분석: 가장 많이 쓴 카테고리
- 데이터 초기화 (확인 후 전체 삭제)

## 사용된 Python 개념

- 변수와 자료형, 문자열 다루기
- 리스트와 딕셔너리 (거래 목록, 카테고리별 합계·예산)
- 함수로 기능 나누기
- 조건문(if/elif/else)과 반복문(while, for)
- 파일 입출력 — `csv` 모듈로 CSV 읽기/쓰기
- 예외 처리 — `try`/`except`로 잘못된 입력 막기
- 표준 라이브러리 — `csv`, `datetime`, `calendar`
